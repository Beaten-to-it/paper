# 연구모형 v0.3: P1-P7 명제 추적표

**상태:** P1-P7은 모두 검증 전 후속 연구 명제다. 아래 표는 근거의 출처와 다음 자료 요구를 추적할 뿐, 현장조사·검증·가설 확정을 뜻하지 않는다.

**증거 표기:** **논문 직접 근거**는 링크된 기여 카드의 원 논문 범위다. **통합 해석**은 여러 카드와 설계를 연결한 해석이다. **후속 연구 명제 (검증 전)**는 연구 1에서 반증 가능하게 다룰 질문이다.

NotebookLM 산출물은 근거로 사용하지 않는다. 승인 전에는 인터뷰, 모집, 이름 생성, 조직 자료 수집을 시작하지 않는다.

## 읽는 방법

각 P 표는 직접 근거와 통합 해석을 별도 행에 둔다. `지지 패턴`은 증명 기준이 아니라 연구 1에서 찾아볼 예상이며, `반증 패턴`과 `경쟁 설명`은 동등하게 기록한다.

`연구 2 처분`은 측정·경계 정제의 방향이다. 연구 1의 자료가 지지하지 않거나 개념 경계가 흐리면 해당 P는 수정·분기·기각하며 H1-Hn으로 바꾸지 않는다.

## P1-P7 추적

### P1 — 역할 보완성·연결성과 발언 판단

**상태:** 후속 연구 명제 (검증 전)

| 항목 | 내용 |
| --- | --- |
| 직접 근거 출처 | [Kemell et al. (2025)](../kemell-2025/model-v0.3-contribution.md)는 공식 도입과 현장 실험의 병존을, [Golgeci et al. (2025)](../golgeci-2025/model-v0.3-contribution.md)는 저항·완화의 개념 축을 제공한다. 어느 카드도 이 경로를 검증하지 않았다. |
| 통합 해석 | 역할의 책임 공백·충돌과 실제 전달 단절을 분리하면, 안전성·효능감의 서로 다른 판단을 설명할 수 있다. |
| 분석 수준 | 역할 보완성·연결성은 사건, 안전성·효능감은 개인×사건이다. |
| 자료원 | 결정적 사건 인터뷰, 역할별 교차 진술, 승인·예외·교육 문서와 네 관계의 유향 기록이다. |
| 지지 패턴 | 역할분담과 전달·수신 확인이 모두 있는 사건에서 복수 구성원이 안전·효능감을 함께 보고한다. |
| 반증 패턴 | 두 조건이 높아도 안전성·효능감이 낮거나, 한 조건이 낮아도 두 판단이 높은 사건이다. |
| 경쟁 설명 | 기존 리더 신뢰, 개인 AI 경험, 과업·데이터 위험도 또는 성공 뒤 관계 강화의 역인과다. |
| 연구 2 처분 | 역할 보완성·연결성·안전성·효능감의 문항을 분리 개발하고 차원성·귀속 규칙을 점검한다. |

### P2 — 발언 안전성과 표면화

**상태:** 후속 연구 명제 (검증 전)

| 항목 | 내용 |
| --- | --- |
| 직접 근거 출처 | [Golgeci et al. (2025)](../golgeci-2025/model-v0.3-contribution.md)는 AI 저항 차원과 조직적 완화의 개념적 연결을 제시한다. 실제 발언 안전성의 효과는 검증하지 않았다. |
| 통합 해석 | 말해도 불이익이 없다는 사건 특화 판단은 우려를 공개 발언이나 간접 발언으로 표면화하는 조건일 수 있다. |
| 분석 수준 | 발언 안전성과 반응은 개인×사건이며, 사건 지배 경로는 파생값이다. |
| 자료원 | 구성원·리더·챔피언 인터뷰, 가상 시나리오, 사건 시간선과 관찰된 반응의 교차 확인이다. |
| 지지 패턴 | 보복 우려가 낮다고 진술한 구성원이 우려를 권한 있는 행위자 또는 신뢰하는 중개자에게 드러낸다. |
| 반증 패턴 | 안전성이 높아도 침묵이 지속되거나, 안전성이 낮아도 공개 발언이 우세한 사건이다. |
| 경쟁 설명 | 정책의 명확성, 이미 알려진 해결책, 직무상 발언 의무 또는 외부 감사 요구다. |
| 연구 2 처분 | 일반 심리적 안전과 구분되는 사건 특화 문항을 인지면접으로 정제한다. |

| 통합 해석 | 문제를 말하면 처리 경로가 실제로 바뀔 수 있다는 기대는 단순 불만을 개선 요구로 전환하는 조건일 수 있다. |
| 분석 수준 | 발언 효능감과 개선 발언은 개인×사건이다. |

| 지지 패턴 | 구성원이 전달 경로와 피드백 가능성을 설명하며 교육·도구·정책의 구체적 변경을 요구한다. |
| 반증 패턴 | 효능감이 높아도 체념·비사용이 나타나거나, 효능감이 낮아도 개선 발언이 지속되는 사건이다. |
| 경쟁 설명 | 높은 개인 전문성, 공식 역할상 보고 의무, 이미 확보된 예산 또는 외부 고객 요구다. |
| 연구 2 처분 | 효능감 문항을 안전성·리더 호의·실제 해결과 분리하고 처리 경로의 이해도를 점검한다. |

| 통합 해석 | 안전하거나 효과적인 발언 경로가 없다고 판단하면 침묵·비사용·우회가 조직 학습에서 보이지 않게 될 수 있다. |
| 분석 수준 | 안전성·효능감과 개인 반응은 개인×사건이며, 은폐·이탈은 사건 지배 경로 후보다. |
| 자료원 | 사건 인터뷰, 가상 시나리오, 승인·예외 절차와 가능한 비식별 정책 기록이다. |
| 지지 패턴 | 구성원이 보복·무용성 우려와 함께 비사용·우회·비공식 실험을 설명하고 공식 경로에는 신호가 남지 않는다. |
| 반증 패턴 | 낮은 판단에도 우려가 건설적으로 표면화되거나, 높은 판단에도 은폐·이탈이 나타난다. |
| 경쟁 설명 | 실용적 대안 부재, 긴급 과업, 데이터 위험, 도구 접근성 또는 개인의 규정 해석 차이다. |
| 연구 2 처분 | 우회의 의도·필요성·위험·공식 대안을 분리해 반응경로 코딩을 정제한다. |

| 통합 해석 | 우려가 검토·조정으로 표면화되고 실질 처리까지 이어지면 정합성과 책임 있는 채택의 조건이 형성될 수 있다. |
| 분석 수준 | 지배 경로와 후행 과정결과는 사건, 원거리 결과는 후속 팀·조직 결과 후보다. |

| 지지 패턴 | 표면화 사건 뒤에 정책·도구·교육·예외가 업무 요구와 맞게 바뀌고 검증·책임 경계가 유지된다. |
| 반증 패턴 | 표면화·처리 뒤에도 정합성이나 책임 있는 사용이 악화되거나, 은폐 사건 뒤에 더 좋은 결과가 나타난다. |
| 경쟁 설명 | 보안·법무·고객 요구, 예산 확대, 기술 성숙 또는 고성과 팀의 공통원인이다. |
| 연구 2 처분 | 지배 경로와 실질 처리·문제해결을 독립 측정하지 않고, 원거리 결과의 별도 구성개념을 정제한다. |

| 통합 해석 | 고발산 AI 사건은 부서 경계를 잇는 연결에, 저발산 사건은 팀 내부 응집·강한 관계에 더 의존할 수 있다. |
| 분석 수준 | 변화 발산성과 활성화된 연결성은 사건, 기초 네트워크 구조는 팀 맥락이다. |
| 자료원 | 업무·전문성·권한·책임 문서, 사건별 유향 관계와 팀 맥락의 중개자 의존·응집성 기술값이다. |
| 지지 패턴 | 고발산 사건에서 경계 연결이, 저발산 사건에서 내부 응집·신뢰가 조정의 조건으로 반복된다. |
| 반증 패턴 | 발산성 방향과 반대로 같은 구조가 반복적으로 유리하거나, 관계 구조가 설명력을 보이지 않는다. |
| 경쟁 설명 | 과업 위험도, 부서 권한, 외부 규제, 조직 규모 또는 변화주도자 선택효과다. |
| 연구 2 처분 | 네 관계가 한 요인으로 묶이는지 확인하고, 브로커리지·응집성·관계강도는 확정 가설이 아닌 측정·탐색 결과로 정리한다. |

| 경쟁 설명 | 기존 갈등, 업무 과부하, 관리 압력, 개인 간 권력차 또는 챔피언 역할 과부하다. |
| 연구 2 처분 | 수신자 태도·관계강도와 관계압력·손상·소진을 분리하고, 후자는 탐색적 과정결과로만 유지한다. |

## 판정 경계

**논문 직접 근거:** 다섯 기여 카드는 각 연구의 맥락과 한계를 보존한다. 연결된 카드를 한데 모아도 P1-P7의 직접 증거가 되지 않는다.

**통합 해석:** P5의 같은 검정에서는 지배 경로 판정과 후행 과정결과를 독립항으로 함께 넣지 않는다. 전달 성공과 실제 문제해결도 같은 변수로 합치지 않는다.

**후속 연구 명제 (검증 전):** 연구 1은 지지 사례만 찾지 않는다. 높은 보완성·연결성에도 은폐된 사건과, 낮은 조건에도 건설적으로 해결된 사건을 같은 표의 반증 패턴으로 기록한다.
