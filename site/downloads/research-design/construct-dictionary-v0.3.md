# 연구모형 v0.3 구성개념 사전

**상태:** 현장조사 전 정의·코딩 계약이다. P1-P7은 모두 검증 전이며, 이 사전은 현장자료의 존재나 모형의 실증을 주장하지 않는다.

**증거 표기:** **논문 직접 근거**는 각 [기여 카드](proposition-traceability-v0.3.md)의 원 논문 범위다. **통합 해석**은 이 사전의 경계 설정이다. **후속 연구 명제 (검증 전)**는 연구 1에서 수정, 분기 또는 기각할 명제다.

NotebookLM 산출물은 근거로 사용하지 않는다. 관찰 가능한 근거는 IRB와 기업 보안·법무 승인 뒤 수집할 익명화 인터뷰·문서의 후보일 뿐이다.

## 사용 원칙

**논문 직접 근거:** 카드가 다루는 조직·표본·이론의 경계를 넘지 않는다. 특히 NHS 네트워크 결과는 SW·AI 조직의 직접 검증 결과가 아니다.

**통합 해석:** 사건 안에서 실행된 역할분담, 실제로 활성화된 관계, 인식, 행동, 후행 결과를 시간 순서로 분리한다.

**후속 연구 명제 (검증 전):** P1-P7의 구성개념은 연구 1의 반례와 연구 2의 측정모형을 통과해야만 후속 가설의 후보가 된다.

| 정의 | 공식 변화관리 권한 없이 AI 활용의 실험·코칭·위험 발견·경계 연결을 실제로 반복하는 사람이다. |
| 포함 | 선행 실험, 동료 코칭, 실패 뒤 개선, 의사결정자 연결과 현장 위험 전달이다. |
| 제외 | 자기 지명, 조직이 미리 지정한 호칭, 공식 권한만 있는 사람은 포함하지 않는다. |
| 관찰 가능한 근거 | 동료 이름지목, 리더 진술, 관찰 가능한 사건·산출물 중 두 종류 이상 근거다. |
| 시간적 위치 | 사건 전후에 반복된 행동을 확인하되, 사건별 동원 역할은 별도로 코딩한다. |
| 가장 가까운 경쟁 구성개념 | 공식 리더 및 AI 활용 숙련자다. |
| 귀속 규칙 | 공식 권한 없이 영향 행동이 반복되면 챔피언으로 기록한다. 공식 지위와 챔피언 행동은 별도 변수다. |
