# NotebookLM 활용 프롬프트: Kemell et al. (2025)

## 1. 첫 노트북 구성

첫 실험에서는 다음 PDF **한 편만** 소스로 넣는다.

`Kemell-et-al-2025-Still-just-personal-assistants.pdf`

한 노트북에 여러 논문을 처음부터 섞지 않는 이유는 각 설명과 슬라이드의 출처를 이 논문의 페이지까지 추적하기 위해서다. 분석 카드와 문헌 비교표는 NotebookLM 밖에서 사실 확인 기준으로 사용한다.

## 2. 공통 지시문

아래 문장을 각 생성 요청의 맨 앞에 붙인다.

```text
업로드된 원문만 근거로 사용하라. 논문이 직접 보고한 사실, 저자의 해석, 네가 도출한 추론을 명확히 구분하라. 모든 핵심 주장에 원문 페이지 또는 절을 표시하라. 원문에 없는 변화주도자, AI 챔피언, 네트워크 관계를 논문이 검증한 것처럼 쓰지 마라. 불확실하거나 확인되지 않는 내용은 '원문에서 확인되지 않음'이라고 표시하라.
```

## 3. 한국어 음성 요약

```text
경영정보학 박사과정 초보자를 대상으로 한국어 오디오 개요를 작성하라. 연구배경, 연구질문, 연구방법, 주요 결과, 장점, 한계, 후속 연구질문 순서로 설명하라. 영문 핵심용어는 처음 나올 때 괄호에 병기하라.

특히 다음을 집중적으로 설명하라.
1. 7개 사례기업에서 하향식, 상향식, 혼합형 도입이 어떻게 달랐는가
2. 공식 조직 라이선스와 구성원의 비공식 도구 사용이 어떻게 병존했는가
3. 저자가 변화 저항과 Shadow IT를 어떤 근거로 언급했는가
4. 저항에 대한 증거가 왜 충분하지 않은가
5. 이 논문이 공식 리더와 비공식 AI 챔피언의 역할 네트워크 연구에 남기는 공백은 무엇인가

약 12-15분 분량으로 구성하고, 마지막 2분에는 '논문이 말한 것'과 '후속 연구자가 해석할 수 있는 것'을 다시 구분해 요약하라.
```

## 4. 상세형 PPT 초안

```text
12장 내외의 박사 세미나용 상세 슬라이드 초안을 한국어로 작성하라.

1장: 서지정보와 한 문장 핵심
2장: 연구배경과 기존 연구의 공백
3장: 연구질문 3개
4장: 다중 사례연구 설계
5장: 사례·인터뷰·종단 관찰 자료
6장: 생성형 AI 도입 방식의 유형(하향식·상향식·혼합형)
7장: 25개 과업과 개인 보조도구 중심 사용
8장: 조직·개인 수준의 도입 장애요인
9장: 공식 도입과 비공식 사용, Shadow IT
10장: 변화 저항 관련 발견과 증거의 한계
11장: 연구의 강점과 방법론적 한계
12장: 공식 리더-비공식 AI 챔피언 네트워크 연구로 이어지는 질문

각 장마다 제목, 핵심 메시지 1문장, 본문 3-5개, 추천 도형, 원문 페이지를 제시하라. 원문에 없는 개념은 '후속 연구 해석' 표식을 붙여라.
```

## 5. 인포그래픽 초안

```text
한 페이지 세로형 인포그래픽 구조를 한국어로 설계하라. 중심 제목은 'SW 조직의 생성형 AI 도입: 공식 정책과 현장 실험의 병존'으로 한다.

상단: 7개 유럽 SW 기업, 인터뷰 15건, 종단 관찰 8개월
중단 왼쪽: 하향식·상향식·혼합형 도입
중단 오른쪽: 25개 과업, 12개 편익, 10개 도전
하단 왼쪽: 공식 라이선스 밖 사용과 Shadow IT 가능성
하단 오른쪽: 저항 증거가 얇은 이유
맨 아래: '공식 리더와 비공식 AI 챔피언은 누가 무엇을 맡는가?'라는 후속 질문

각 숫자와 주장에 원문 페이지를 붙이고, 사실과 후속 연구 해석을 색상이나 라벨로 구분하라. 논문에 없는 네트워크 구조를 사실처럼 시각화하지 마라.
```

## 6. 비판적 읽기 대화

```text
이 논문을 질적 연구 방법론 심사위원의 관점에서 검토하라. 아래 표 형식으로 답하라.

평가항목 | 원문 근거와 페이지 | 강점 | 위험 또는 한계 | 추가 확인 질문

평가항목은 연구질문-설계 정합성, 사례선정, 응답자 구성, 자료 삼각검증, 종단성, 코딩 신뢰성, 부정 사례, 연구자 편향, 자기보고 편향, 외적 타당성, 윤리·이해상충, 데이터·도구 공개를 포함하라.

저항, 생산성, 조직 변화에 관한 주장이 실제 자료의 범위를 넘어서는지 특별히 점검하라.
```

## 7. 박사논문 연결 질문

```text
이 논문이 직접 답하지 못한 질문만 추출하라. 다음 네 범주로 분류하라.

1. 공식 리더의 역할
2. 비공식 AI 챔피언의 역할
3. 두 역할 사이의 네트워크와 역할 분담
4. 저항·양가감정·비공식 실험·Shadow AI의 관리

각 질문에 대해 원문에서 발견되는 출발 단서와 페이지, 원문에 없는 추가 개념, 필요한 자료원을 표시하라. 논문이 검증하지 않은 인과관계를 단정하지 마라.
```

## 9. 결과 검증 프롬프트

오디오·슬라이드·인포그래픽을 만든 뒤 아래 요청으로 자체 점검한다.

```text
방금 만든 결과에서 검증 가능한 주장과 숫자를 모두 추출하라. 각 항목을 다음으로 분류하라.

A. 원문에서 직접 확인되며 페이지가 정확함
B. 원문에 있으나 표현이 과장되거나 맥락이 빠짐
C. 원문에 없고 합리적 추론에 불과함
D. 원문과 충돌하거나 확인할 수 없음

B-D 항목은 원문에 맞도록 수정문을 제시하라. 출처 페이지를 찾지 못하면 추측하지 마라.
```

## 10. 사용자가 직접 확인할 체크리스트

- [ ] 표본 수, 사례 수, 기간, 회의 수가 원문과 일치하는가
- [ ] 인식된 편익을 실제 생산성 향상으로 바꾸어 말하지 않았는가
- [ ] 한 명의 회의적 참여자를 조직 전체 저항으로 일반화하지 않았는가
- [ ] 관심 있는 직원 중심의 선택적 도입 한계를 언급했는가
- [ ] 공식 제공 밖 사용과 실제 보안사고를 혼동하지 않았는가
- [ ] Shadow IT를 “발생이 입증됨”이 아니라 “잠재적 문제”로 표현했는가
- [ ] AI 챔피언·변화주도자 네트워크를 논문의 직접 결과로 잘못 제시하지 않았는가
- [ ] 최종 인용은 NotebookLM 결과가 아니라 원문 PDF를 보고 작성했는가

NotebookLM 산출물은 빠른 이해와 복습용이다. 학위논문의 근거와 인용은 반드시 원문, 서지DB, 분석 카드에서 다시 확인한다.
