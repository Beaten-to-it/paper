# NotebookLM 활용 프롬프트: Battilana & Casciaro (2012)

## 공통 지시문

```text
업로드된 원문만 근거로 사용하라. 구조적 공백, 네트워크 폐쇄성, 변화 괴리도, 변화 발의, 변화 채택을 구분하라. 구조적 공백이 언제나 좋다고 단순화하지 마라. 공식 리더와 비공식 AI 챔피언의 공동 네트워크는 후속 연구 해석이며 원 논문의 검증 결과가 아니다. 각 주장에 원문 페이지 또는 절을 표시하라.
```

## 한국어 음성 요약

```text
경영정보학 박사과정 초보자를 위한 12-15분 한국어 오디오 개요를 작성하라. 먼저 구조적 공백과 네트워크 폐쇄성을 쉬운 예로 설명하고, 변화 괴리도가 왜 조건변수인지 설명하라. 68개 NHS 변화 프로젝트와 12개월 종단설계를 요약한 뒤, 고괴리 변화에는 중개형 네트워크가, 저괴리 변화에는 응집형 네트워크가 유리하다는 결과를 정확히 설명하라. 마지막에는 이 논리를 공식 리더-비공식 AI 챔피언 네트워크에 적용할 때 검증이 필요한 부분을 구분하라.
```

## 세미나 PPT 초안

```text
12장 내외의 한국어 박사 세미나 슬라이드 초안을 작성하라.
1장 서지정보와 한 문장 핵심
2장 변화는 사회적 영향 과정이라는 문제의식
3장 구조적 공백과 폐쇄성
4장 변화 괴리도
5장 가설 1과 2
6장 68개 프로젝트와 12개월 연구설계
7장 네트워크 측정
8장 변화 괴리도·채택 측정
9장 변화 발의 결과
10장 채택의 교차 상호작용
11장 강점과 한계
12장 공식 리더-비공식 AI 챔피언 네트워크 확장
각 장에 핵심 메시지, 본문, 추천 도형, 원문 페이지를 제시하라.
```

## 시각화 지시

```text
2x2 매트릭스를 설계하라. 가로축은 낮은 폐쇄성(구조적 공백)에서 높은 폐쇄성(응집)으로, 세로축은 낮은 변화 괴리도에서 높은 변화 괴리도로 둔다. 논문이 지지한 상대적 유리 조건만 표시하고, AI 조직에 대한 적용은 '후속 연구 가설' 영역으로 분리하라.
```

## 비판적 검증

```text
다음 오해를 원문 근거로 반박하라.
1. 구조적 공백은 모든 변화에 유리하다.
2. 네트워크 중심성과 폐쇄성은 같은 개념이다.
3. 논문은 공식·비공식 변화주도자 쌍을 분석했다.
4. NHS 결과는 곧바로 한국 SW 조직에 일반화된다.
5. 종단설계이므로 인과가 완전히 확정됐다.
```

## 최종 체크리스트

- [ ] 변화 발의와 변화 채택을 구분했는가
- [ ] 구조적 공백의 주효과가 아니라 조건부 효과를 설명했는가
- [ ] 고괴리·저괴리 변화에서 유리한 구조를 뒤바꾸지 않았는가
- [ ] 자아중심 네트워크와 전체 네트워크를 혼동하지 않았는가
- [ ] 공식 리더-비공식 챔피언 확장을 후속 연구 해석으로 표시했는가
