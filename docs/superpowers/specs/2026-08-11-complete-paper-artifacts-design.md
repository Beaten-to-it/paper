# 5편 논문 전체 산출물 완성 설계

## 1. 목적

Paper Lab의 다섯 논문을 동일한 산출물 구조로 정리하고, 현재 `미생성`인 항목을 모두 완성한다. 사용자는 회사에서도 공개 GitHub Pages를 통해 원문 접근, 한국어 이해 자료, 음성, 발표자료와 시각 요약을 이용할 수 있어야 한다.

공개 편의보다 저작권과 연구 무결성을 우선한다. 공개 재배포가 허용된 논문만 원문 PDF와 전문 한국어 번역본을 게시한다. 권리가 제한된 논문은 공식 원문 링크와 한국어 상세 해설본을 공개하고, 개인 학습용 전문 번역본은 연구 작업공간에만 보관한다.

## 2. 채택한 접근법

### 접근법 A - 모든 파일 공개

가장 편리하지만 Battilana & Casciaro (2013)의 INFORMS 최종 출판본과 전문 번역을 무단 재배포하게 될 위험이 있어 채택하지 않는다.

### 접근법 B - 모든 원문을 링크로만 제공

권리 위험은 가장 낮지만 CC BY 논문의 공개·번역 가능성을 활용하지 못하고 사용자의 빠른 학습 목적을 충분히 충족하지 못해 채택하지 않는다.

### 접근법 C - 권리 기반 공개·비공개 분리

채택안이다. CC BY 4.0 세 편은 원문과 연구용 전문 번역을 공개한다. 나머지 두 편은 공식 원문 링크와 한국어 상세 해설본을 공개하고, 전문 번역은 로컬 비공개로 보관한다. 모든 논문은 화면상 동일한 슬롯 구조를 유지한다.

## 4. 논문별 표준 산출물

다섯 논문은 모두 아래 9개 공개 슬롯을 갖는다.

1. `원문`: CC BY는 다운로드 가능한 PDF, 제한 논문은 공식 원문 링크
2. `한국어본`: CC BY는 비공식 전문 번역 PDF, 제한 논문은 한국어 상세 해설 PDF
3. `분석`: 비판적 분석 카드
4. `NotebookLM 프롬프트`: 단일 원문 기반 생성 지시문
5. `NotebookLM 실행기록`: 소스·생성 조건·검증·해시 기록
6. `음성`: 한국어 심층 분석 오디오
7. `PPT`: 편집 가능한 박사 세미나 발표자료
8. `슬라이드 PDF`: 발표자료 PDF
9. `인포그래픽`: 한 페이지 핵심 시각 요약

현재 다섯 논문 35개 슬롯과 연구설계 4개 슬롯에 원문·한국어본 10개를 추가한다. 완료 시 총 49개 슬롯이 모두 `complete`가 되며 `missing`은 0개가 된다. 제한 논문의 공개 대체물도 실제 파일이나 공식 링크가 존재할 때만 `complete`로 표시한다.

## 5. 번역 산출물 규칙

### CC BY 전문 번역

- 제목 페이지에 원저자, 원제, DOI, 원문 라이선스, 원문 URL을 표시한다.
- `AI 보조 비공식 한국어 번역이며 인용은 원문을 기준으로 한다`는 고지를 넣는다.
- 번역이 변경·각색임을 표시하고 CC BY 4.0 링크를 제공한다.
- 장·절, 표·그림 번호, 가설, 표본 수, 통계값과 참고문헌을 보존한다.
- 제3자 자료로 별도 표시된 이미지가 있으면 복제하지 않고 원문의 해당 위치를 안내한다.
- 영문 전문을 병렬로 반복하지 않고 한국어 번역 중심으로 구성해 가독성을 확보한다.

### 제한 논문

- 공개 상세 해설은 초록, 이론, 가설, 방법, 주요 결과, 강점, 한계와 본 연구 연결을 충분히 설명하되 원문을 대체할 정도의 연속적 번역은 싣지 않는다.
- 공개 문서의 첫 페이지에 `전문 번역 아님`과 공식 원문 링크를 표시한다.
- 개인 학습용 전문 번역에는 `비공개·재배포 금지` 워터마크와 원문 권리 정보를 넣는다.
- 비공개 원문과 번역 파일은 Git 저장소, GitHub Release와 Pages에 포함하지 않는다.

## 6. 신규 미디어 산출물

Golgeci (2025), Battilana & Casciaro (2012), Battilana & Casciaro (2013)에 다음을 생성한다.

- 한국어 NotebookLM 심층 분석 오디오 1개
- 11-13장 박사 세미나 PPT 1개
- 동일 슬라이드 PDF 1개
- 세로형 인포그래픽 1개
- NotebookLM 실행·검증 기록 1개

NotebookLM에는 매번 해당 논문 한 편만 소스로 등록한다. 실행기록에는 소스 수, 생성일, 언어, 표시 길이, 파일 규격, 크기, SHA-256과 검증 결과를 남기되 비공개 Notebook URL은 공개하지 않는다.

PPT는 원문이 직접 확인한 사실, 저자의 이론적 해석, 박사논문용 후속 제안을 색과 라벨로 구분한다. 모든 슬라이드 발표자 노트에 `[Sources]` 블록을 넣는다. 인포그래픽은 텍스트 정확성을 우선하며 자동 생성본에 오류가 있으면 교정본을 별도로 만든다.

## 7. 사이트와 카탈로그 변경

카탈로그에 다음 메타데이터를 추가한다.

- `rights.license`
- `rights.redistribution`
- `rights.translation_publication`
- `rights.source_url`
- `rights.checked_at`
- `translation_kind`: `full_unofficial` 또는 `detailed_study_guide`

저장 방식은 다음과 같다.

- 작은 Markdown·인포그래픽: Pages의 `site/downloads/`
- 공개 가능한 원문·번역 PDF, 음성, PPT, 슬라이드 PDF: GitHub Release
- 제한 논문 원문: 승인된 공식 출처의 HTTPS 링크
- 제한 논문 개인 번역: 연구 작업공간 `output/private-translations/`

사이트 카드에는 `CC BY 4.0`, `공식 원문 링크`, `비공식 전문 번역`, `전문 번역 아님`, `비공개 전문본 보관` 배지를 구분해 표시한다.

## 8. 검증과 실패 처리

### 자동 검증

- 다섯 논문에 9개 슬롯이 정확히 존재하고 `missing`이 0개인지 검사한다.
- Pages 파일과 Release 자산의 크기·SHA-256을 검사한다.
- 원문 PDF 공개는 권리 메타데이터가 허용하는 경우에만 통과시킨다.
- 외부 원문 링크는 HTTPS, 허용된 공식 호스트와 논문별 DOI를 검사한다.
- 미등록 파일, 소스 PDF 위장, 경로 탈출, 비공개 Notebook URL과 로컬 경로 공개를 차단한다.
- 제한 논문의 원문·전문 번역 파일이 Git 추적 또는 Release 자산에 포함되면 실패한다.

### 시각·미디어 검증

- 번역 PDF와 상세 해설 PDF의 모든 페이지를 PNG로 렌더링해 잘림·깨짐·빈 페이지를 확인한다.
- 모든 PPT 슬라이드를 개별 렌더링하고 오버플로·겹침·출처 노트를 검사한다.
- 슬라이드 PDF의 페이지 수와 PPT 슬라이드 수가 일치해야 한다.
- 오디오는 `ffprobe` 메타데이터와 전체 디코딩으로 확인한다.
- 인포그래픽은 확대 검토로 숫자, 저자·연도, 핵심 문구와 한글 표기를 확인한다.
- 공개 사이트는 데스크톱·모바일에서 검색, 필터, 문서 뷰어, 다운로드와 오디오 재생을 점검한다.

NotebookLM이나 이미지 생성 서비스가 실패하면 임의의 파일로 완료 표시하지 않는다. 동일 소스와 지시로 복구를 시도하고, 실제 산출물과 검증이 확보될 때까지 배포를 보류한다.

## 9. 완료 조건

- 공개 사이트의 다섯 논문이 각 9개 산출물을 제공한다.
- 공개 카탈로그는 49개 슬롯, 49개 완료, 0개 미생성을 표시한다.
- CC BY 세 편의 원문과 비공식 전문 한국어 번역을 다운로드할 수 있다.
- 제한 두 편은 공식 원문 링크와 한국어 상세 해설을 제공하며, 전문 번역은 로컬 비공개로만 존재한다.
- 신규 세 편의 NotebookLM 음성·PPT·PDF·인포그래픽·실행기록이 모두 생성·검증되어 있다.
- 제3자 권리 제한 자료, 비공개 Notebook URL, 회사 기밀·개인정보와 QA 임시파일이 공개되지 않는다.
- 로컬 테스트, GitHub Actions, 실제 공개 URL 검사와 최종 적대 검토에서 `Critical = 0`, `High = 0`을 충족한다.
